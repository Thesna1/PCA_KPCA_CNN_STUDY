# PCA_KPCA_CNN_STUDY
Implementing PCA with CNN for better forecasting, regression and classification.

This project implements and compares the performance of Principal Component Analysis (PCA) and Kernel Principal Component Analysis (KPCA) as a feature reduction and weighting layer for Convolutional Neural Networks (CNNs).


This projects combines PCA’s strength in dimensionality reduction and noise removal with CNNs' ability to learn hierarchical features. Intially we preprocess the input data with PCA, which reduces the complexity and takes only the most relevant information. Then the CNN focus only on  meaningful patterns, making learning more efficient and improving performance in tasks like classification, regression, and forecasting.
This model reduces the computational load and speeds up training time. On otherside its improving the accuracy. Compared to the traditional CNN this model have higher accuracy, faster execution and better generalisation.
